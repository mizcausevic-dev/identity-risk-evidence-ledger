# Security

`identity-risk-evidence-ledger` includes an offline analyzer, CLI, and public synthetic executive dashboard for identity-risk posture. It does **not** store live tenant credentials, perform live directory fetches, or expose authenticated write paths.

## Reporting

- [Open a security advisory](https://github.com/mizcausevic-dev/identity-risk-evidence-ledger/security/advisories/new)
- Or open a private issue if GitHub advisories are not available in your context
